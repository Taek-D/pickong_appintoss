# 픽콩 — 자사앱 어뷰징 차별화 코멘트 (검수 첨부용)

> PRD §5.3 기반. "기존 자사 미니앱과 기능 본질·UX·결과물·정보구조 모두 상이"를 입증.

## 비교

| 비교축 | 커피 트래킹 | 작심삼일 루틴 챌린지 | **픽콩** |
|---|---|---|---|
| **본질** | 줄이고 싶은 행동 모니터링 | 시작하고 싶은 행동 반복 | **마음에 든 것 수집·도감** |
| **기록 단위** | 잔/날짜 | 루틴 완료 체크 | 카테고리·금액·이모지·메모 |
| **결과물** | 절감 통계 | 연속 성공 그래프 | **취향 캐릭터·도감 카드(서버 저장·월 단위 공유)** |
| **감정 톤** | 절제·반성 | 도전·습관 | 귀여움·자랑 |
| **화면 IA** | 캘린더형 | 챌린지형 | 그리드 도감형 |

## 핵심 차이점

1. **본질**: 픽콩은 "수집·도감" 메타포. 사용자가 좋아하는 것을 모은다는 행위 자체가 가치 — 절제(커피)나 도전(챌린지)이 아닌 자랑·즐김의 동기 구조.

2. **결과물**: 픽콩만이 **월간 캐릭터 카드** 결과물을 갖는다. 8가지 카테고리 분포 → 8종 캐릭터 룰베이스 → 공유 가능한 카드 (8자 hash card_id, 본인 영구·공유 월 만료). 커피·루틴 앱은 통계/그래프만 산출.

3. **공유 라이프사이클**: 픽콩은 본인 카드는 영구, 공유 카드는 월 만료. "이번 달 취향"이라는 시간 단위 자랑형 콘텐츠. 다른 앱은 공유 자체가 없거나 통계 캡처만.

4. **다크패턴 회피 강력**: PRD §5.5의 5종(특히 4번 예상치 못한 광고)을 구조적으로 차단 — 광고는 위치 A 단일 지점·월 1회 단일 캡·silent skip. 사용자가 명시 클릭한 "이번 달 카드 보기" 직전에만.

5. **개인정보 최소 수집**: 토스 로그인 외 권한 0건, 사진 업로드 0건, 카드 데이터에 텍스트 메모 미저장 (단말 only). 외부 호스팅 자산 0건 (OG 이미지 미사용).

## 소비 조장 우려에 대한 명시적 대응

출품폼 챌린지 연관성 카피에 명문화: **"소비를 반성하는 가계부가 아니라, 좋아한 마음을 가볍게 자랑하는 픽콩만의 귀여움 표현 방식이에요."** 금액은 선택값(빈값 허용), 카드 데이터에 할인·쇼핑 링크 0건.
