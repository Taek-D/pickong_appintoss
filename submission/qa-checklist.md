# QR 회귀 테스트 체크리스트 (Phase 4)

> 콘솔 업로드 후 토스앱 QR 스캔으로 실 디바이스 회귀. PRD §11.1 + Phase 3 회수분 우선.

## 디바이스 (PRD §11.2)
- [ ] iOS 최신 + iOS-1
- [ ] Android 메인 해상도 2종

## 환경
- [ ] 토스앱 샌드박스 (콘솔 안내)
- [ ] 토스앱 피처 테스트 (콘솔 안내)

## A. Foundation (Phase 1)
- [ ] 신규 진입 → 온보딩 슬라이드 3장 → 토스 로그인 → 닉네임 추천 칩 1탭 → S-HOME
- [ ] 닉네임 5케이스: 빈값 / 자모 단독("ㄱ") / 이모지 / 공백 / 관리자 사칭("toss") 모두 차단 토스트
- [ ] 닉네임 정상값 (한글 1자/영문 10자/한글 10자/숫자 5자) 통과
- [ ] 도감 그리드 8칸 정상 + 빈 카테고리 점선 표시
- [ ] 콩 등록 3단계 → 30초 내 완료 → S-DONE → 그리드 갱신 확인
- [ ] S-CAT 진입 → 등록 콩 1건 노출 / empty 상태 카피

## B. Card·Share·Ad (Phase 2)
- [ ] 도감 3개 이상 등록 → "이번 달 카드 보기" 활성
- [ ] 첫 클릭 → 광고 1.5s 타임아웃 → S-CARD 자연 진입 (silent skip 또는 광고 노출 후)
- [ ] S-CARD 본문 하단 "친구는 이번 달 안에만 볼 수 있어요" 매번 노출
- [ ] 두 번째 클릭 (같은 달) → 광고 없이 즉시 S-CARD
- [ ] "공유하기" → S-SHARE 시트 → "이미지 저장" 정상 / "토스로 공유하기" 정상
- [ ] 공유 메시지 미리보기: 닉네임 9자/10자 시 컷오프 없음 확인
- [ ] 공유 링크 다른 디바이스로 받아서 진입 → 본인이면 본인 분기, 타인이면 "{닉네임}의 이번 달 카드예요"

## C. S-CARD-VIEW 4분기 (회수분 우선)
- [ ] 본인 카드 + active → "이번 달 나는 {character}"
- [ ] 타인 카드 + active 같은 달 → "{닉네임}의 이번 달 카드예요"
- [ ] 만료 (이전 달, share_status=expired) → "이 카드는 지난 달 이야기예요"
- [ ] 잘못된 hash → "카드를 찾을 수 없어요"

## D. 닉네임 변경 동기화 (회수분)
- [ ] /set/nickname → 새 이름으로 변경 → 토스트
- [ ] S-CARD 재진입 → 새 nickname_snapshot 반영
- [ ] 다른 달 카드 (시간 모킹) → nickname_snapshot 변경 없음

## E. 회원 탈퇴
- [ ] /set → "내 도감 데이터 삭제" → confirm sheet → 데이터 삭제
- [ ] S-ONB로 복귀 + Storage clear 확인
- [ ] 같은 user_key 재로그인 → 신규 가입 처리 (닉네임 미입력 + viewer_intro_seen 미저장)
