# Plan 01-01: Scaffold

## Goal
Vite + React 19 + Tailwind 4 + `@apps-in-toss/web-framework@2.0.1` 프론트엔드와 Hono + Postgres 백엔드의 개발 가능한 최소 스켈레톤을 구축한다. `pnpm dev`로 양쪽이 동시에 뜬다.

## Requirements covered
- F000a (Vite + React 19 + Tailwind 4 스캐폴드)
- F000b (백엔드 mTLS + Express/Nest 스켈레톤 — Hono로 변경)
- F000c (Storage 키 정의 + cute_items 모델)
- F000d (라우팅 + getSchemeUri 카드 ID 파싱)

## Steps

### 1. 루트 패키지 워크스페이스
- `package.json` (private, workspaces: ["client", "server", "shared"])
- `pnpm-workspace.yaml`
- `.gitignore` (node_modules, dist, .env, certs/, .planning/phases/*/scratch/)
- `.env.example` (DATABASE_URL, TOSS_CLIENT_ID, TOSS_CLIENT_SECRET, TOSS_MTLS_CERT_PATH, TOSS_MTLS_KEY_PATH, SENTRY_DSN, SESSION_SECRET)
- `tsconfig.base.json` (공유 strict TS 설정)

### 2. shared/ 패키지 (frontend ↔ backend 타입 공유)
- `shared/package.json`
- `shared/tsconfig.json`
- `shared/src/types.ts` (Account, MonthlyCard, CuteItem, NicknameError, EventName)
- `shared/src/constants.ts` (CATEGORIES, RECOMMENDED_NICKNAMES, RECOMMENDED_EMOJIS, REGEX)
- `shared/src/index.ts` (re-export)

### 3. client/ (현재 루트의 frontend)
- 기존 `granite.config.ts`, `index.html`을 client/로 이동? → **NO**. SDK가 루트 expects. 루트에 그대로 두되 `client/` 별도 디렉토리는 없음. 결국 모노레포 대신 **단일 루트 + server/** 구조로 단순화.

→ **수정 결정**: 워크스페이스 폐기, 단일 루트 구조:
- `package.json` (frontend deps + scripts)

### 4. 개발 스크립트
- `package.json` scripts:
  - `dev`: concurrently `vite` + `tsx watch server/src/index.ts`
  - `build`: `vite build`
  - `typecheck`: `tsc --noEmit -p . && tsc --noEmit -p server`
  - `db:migrate`: psql + 001_init.sql 적용
  - `lint`: `tsc --noEmit` (eslint optional)

### 5. Storage 키 (PRD §13.2 그대로)
| Key | Value | Used by |
|---|---|---|
| `user_key:current` | string | session |
| `nickname:current` | string | header |
| `cute_items:{user_key}` | CuteItem[] JSON | items store |
| `summary:{user_key}:{ym}` | object JSON | home cache |
| `ad_card_shown:{user_key}:{yyyymm}` | boolean | Phase 2 ad cap |
| `onboarding_completed` | boolean | onboarding |
| `viewer_intro_seen:{user_key}` | boolean | Phase 2 viewer intro |

### 6. Web fallback for SDK
- `src/lib/sdk.ts`에서 dynamic import 후 `isSupported()` false면 mock:
  - `appLogin()` → return `{ user_key: 'mock-' + uuid }`
  - `Storage.setItem/getItem` → localStorage
  - `useBackEvent` → no-op
  - `IntegratedAd` → fake load 1.5s + show 0.5s
  - `getTossShareLink` → return `https://example.com/card/{8-hash}`
  - `share` → console.log + clipboard
