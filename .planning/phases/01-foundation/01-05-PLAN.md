# Plan 01-05: Diagram + Bean Registration

## Goal
사용자가 S-HOME 도감 그리드에서 BottomCTA를 누르면 카테고리 → 금액 → 이모지·메모 3단계로 30초 내 콩을 등록하고, S-DONE에서 수집률 갱신을 확인하며, S-CAT 카테고리 상세에서 본인 기록을 본다.

## Requirements covered
- HOME-01 (도감 그리드 8칸 + 수집률 + 주간 진행)
- HOME-02 (카드 버튼 조건부 활성)
- HOME-03 (카테고리 상세 + empty)
- ADD-01 (3단계 30초 내)
- ADD-02 (필드 검증)
- ADD-03 (완료 화면 + 광고 트리거 없음)

## Steps

export const CATEGORIES = [
  { id: 'goods',    label: '굿즈',    emoji: '🎁', color: '#FFC0CB' },

### 2. cute_items 단말 모델 + store (`src/state/items.ts`, Zustand)
```typescript
type CuteItem = {
  id: string;        // uuid
  user_key: string;
  category: typeof CATEGORIES[number]['id'];
  amount: number;    // 0+ 정수
  emoji: string;
  memo: string;      // 0~60
  created_at: string; // iso8601
};

state: { items: CuteItem[]; loaded: boolean }
actions: { add(input), update(id, patch), remove(id), loadFromStorage(user_key), refreshSummary() }
```
- Storage 키: `cute_items:{user_key}`
- 로딩: 세션 복원 후 `loadFromStorage(user_key)` 호출
- 변경 시: Storage 즉시 동기화 + summary 캐시 무효화

### 3. summary 계산 (`src/lib/summary.ts`)
```typescript
function buildSummary(items, ym): {
  total_count: number;
  total_amount: number;
  by_category: Record<categoryId, count>;
  collection_rate: number; // 채워진 카테고리 수 / 8
  this_week_count: number;
  weekly_target: number; // 3
}
```
- Storage 캐시: `summary:{user_key}:{ym}`

### 4. S-HOME 화면 (`src/screens/Home.tsx`)
- Top: 좌상단 브랜드 로고 + "픽콩", 우상단 메뉴(설정 진입은 Phase 2)
- 헤더: "이번 달 N% 채웠어요" (수집률) + 진행 게이지(연두)
- 도감 그리드 8칸:
  - 채워진 칸: 컬러 + 카테고리 라벨 + 카운트 Badge
  - 빈 칸: 점선 박스 + 회색 라벨
  - 칸 클릭 → `/cat/:id`
- 주간 진행 텍스트: "이번 주 3콩까지 N콩 남았어요" (this_week_count >= 3 면 "이번 주 목표 달성!")
- 이번 달 카드 보기 버튼:
  - total_count < 3: disabled + 안내 "기록 3개부터 카드를 받을 수 있어요"
  - total_count >= 3: Phase 1에서는 비활성 + 툴팁 "Phase 2에서 카드 기능이 열려요"
  - (Phase 2에서 ad_card_shown 분기 wired)
- BottomCTA "오늘의 콩 줍기" → `/add`
- Analytics: `home_view(is_first_visit, collected_count, month)`, `home_press_add`, `home_press_category(category)`, `home_press_card_unlock(eligible, ad_eligible)`

### 5. S-ADD 3단계 (`src/screens/Add/`)
- step 1: 카테고리 선택 (`AddCategory.tsx`)
  - 8칸 그리드 + 헤드라인 "어떤 귀여움이에요?"
  - 1탭 선택 → step 2 자동 이동
- step 2: 금액 (`AddAmount.tsx`)
  - 헤드라인 "얼마였어요? (선택)"
  - 숫자 키패드 또는 input + "건너뛰기" 버튼
  - 0 이상 정수 검증
  - BottomCTA "다음"
- step 3: 이모지 + 메모 (`AddEmojiMemo.tsx`)
  - 헤드라인 "어떤 콩으로 남길까요?"
  - 추천 이모지 12개 + 직접 입력
  - 메모 textarea (1~24자 권장, 최대 60)
  - 글자 카운터
  - BottomCTA "내 도감에 담기"
- 저장: useState 누적 → 마지막 step에서 `items.add(input)` + Storage 저장 → `/done` 라우팅
- Analytics: `add_step_view(step)`, `add_select_category(category)`, `add_input_amount(amount_band)`, `add_press_save`, `add_save_success`, `add_save_fail`
- amount_band: '0' / '1-1k' / '1k-5k' / '5k-10k' / '10k+'

### 6. S-DONE (`src/screens/Done.tsx`)
- 헤드라인: "{카테고리}콩 하나를 주웠어요" (예: "문구콩")
- 서브: "이번 달 N번째 귀여움이에요. 도감 수집률 X%"
- 일러스트 placeholder (캐릭터 8종은 Phase 2)
- CTA 두 개:
  - Primary BottomCTA "도감 보러가기" → `/`
  - Secondary outline `#7BD389` "하나 더 줍기" → `/add`
- 광고 트리거 없음 (PRD §7.8)
- Analytics: `done_view(category, total_in_month)`, `done_press_home`, `done_press_more`

### 7. S-CAT 카테고리 상세 (`src/screens/CategoryDetail.tsx`)
- 라우트: `/cat/:id`
- Top: 카테고리 라벨 + 좌상단 < 뒤로가기
- 본문: items.filter(category===id) 정렬 (최신순)
  - 각 row: 이모지 + 메모 + 금액 + 날짜 (수정·삭제는 Phase 2)
- empty: 헤드라인 "이 카테고리는 아직 비어 있어요. 하나 담아볼까요?" + BottomCTA "오늘의 콩 줍기"
- Analytics: `cat_view(category)`, `cat_press_add`

### 8. 라우터 가드 (`src/router.tsx`)
- 모든 화면 진입 전 `useEnsureLoggedIn()` 훅 실행
- nickname 미입력이면 `/nick`으로 강제 라우팅

### 9. Analytics 적재
- 클라이언트 wrapper `src/lib/analytics.ts`:
  - `track(eventName, properties?)` → SDK Granite Analytics(있으면) + console.log(개발) + Sentry breadcrumb
  - 모든 화면 mount 시 view 이벤트 자동 적재 (page-load 훅)
