# Plan 01-04: Forbidden Words v1

## Goal
백엔드 닉네임 API에 정적 사전 + 변형 정규식이 적용되어 관리자/공식/픽콩공식 등 사칭 시도가 강력 차단되고, 욕설·혐오는 1차 차단된다. D7까지 운영 배포 완료.

## Requirements covered
- SAFE-01 (정적 사전 + 변형 정규식)
- SAFE-02 (욕설·혐오 1차 차단)
- SAFE-03 (D7 운영 배포)

### 2. `server/data/forbidden_patterns.regex.ts`
변형 정규식 (유니코드 normalize + 분리/치환 변형 catch):
```typescript
export const FORBIDDEN_PATTERNS: { pattern: RegExp; reason: string }[] = [
  // 'toss' 변형: t-o-s-s, t.o.s.s, t0ss, t05s 등
  { pattern: /t[\W_0-9]{0,3}o[\W_0-9]{0,3}s[\W_0-9]{0,3}s/i, reason: 'toss_variant' },
  // '토스' 변형: 토[ ]스, 토ㅡ스, 토_스 등
  { pattern: /토[\s\W_]{0,3}스/u, reason: 'toss_kr_variant' },
  // 'admin' 변형
  { pattern: /a[\W_0-9]{0,3}d[\W_0-9]{0,3}m[\W_0-9]{0,3}i[\W_0-9]{0,3}n/i, reason: 'admin_variant' },
  // '관리자' 변형
  { pattern: /관[\s\W_]{0,3}리[\s\W_]{0,3}자/u, reason: 'admin_kr_variant' },
  // 'official' 변형
  { pattern: /o[\W_0-9]{0,3}f[\W_0-9]{0,3}f[\W_0-9]{0,3}i[\W_0-9]{0,3}c[\W_0-9]{0,3}i[\W_0-9]{0,3}a[\W_0-9]{0,3}l/i, reason: 'official_variant' },
  // '픽콩공식' / '픽콩운영' 변형
  { pattern: /픽[\s\W_]{0,3}콩[\s\W_]{0,3}(공[\s\W_]{0,3}식|운[\s\W_]{0,3}영|관[\s\W_]{0,3}리)/u, reason: 'pickkong_official_variant' },
  // 'pickkong' + admin/official/team 조합
  { pattern: /p[\W_0-9]*i[\W_0-9]*c[\W_0-9]*k[\W_0-9]*k[\W_0-9]*o[\W_0-9]*n[\W_0-9]*g[\W_0-9_]*?(admin|official|team|운영|관리|공식)/i, reason: 'pickkong_combo' }
];
```

### 3. `server/src/lib/forbidden.ts` 모듈
- `loadForbidden()`: JSON + regex 모듈 lazy load
- `normalize(input)`: NFKC unicode normalize + lowercase + 공백/특수문자 제거(비교용 사본)
- `checkNickname(input): { ok: true } | { ok: false, error_code: 'forbidden', reason: string }`
- 검사 순서:
  1. NFKC normalize
  2. exact_match 셋(소문자 비교) 매칭
  3. profanity_light + hate_light 셋 매칭
  4. FORBIDDEN_PATTERNS 정규식 순회
  5. 모두 통과 시 ok

### 4. POST/PATCH /account/nickname에 wire-in
- 01-03에서 미들웨어로 호출: `const check = checkNickname(body.nickname); if (!check.ok) return c.json({ error_code: check.error_code, reason: check.reason }, 400);`
- Analytics `nick_save_fail(error_code='forbidden', reason)` 적재 (reason은 디버깅용 internal log only, response에는 미포함)
